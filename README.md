\# HelpDesk TI



Sistema web para gerenciamento de chamados de suporte técnico desenvolvido em \*\*Python\*\*, \*\*FastAPI\*\* e \*\*SQLite\*\*.



\## Funcionalidades



\* Cadastro de chamados

\* Alteração de status (Aberto, Em andamento e Concluído)

\* Filtro por status

\* Listagem em ordem dos chamados mais recentes

\* Banco de dados SQLite

\* Interface web responsiva



\## Tecnologias utilizadas



\* Python

\* FastAPI

\* SQLite

\* HTML

\* CSS

\* JavaScript



\## Como executar



1\. Clone o repositório.

2\. Crie e ative o ambiente virtual.

3\. Instale as dependências:



```bash

pip install -r requirements.txt

```



4\. Execute o projeto:



```bash

uvicorn app.main:app --reload

```



Acesse:



<escape>http://127.0.0.1:8000</escape>
